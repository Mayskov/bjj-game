# Позиционка

Мобильная браузерная тактическая дуэль по бразильскому джиу-джитсу против локального бота.
Игрок — чёрное ги, бот — белое. 12 обменов, победа по очкам или досрочно сабмишном.
Сервер и сеть для расчёта боя не нужны.

## Запуск

```bash
cd games/pozitsionka
npm install
npm run dev          # http://localhost:5173
npm run build        # typecheck + сборка в dist/ (статические файлы, base: "./")
npm run preview      # раздать собранную версию
```

Тесты отключены: скриптов `test` и `test:e2e` больше нет, сборка их не проверяет.
Файлы тестов оставлены в `tests/` и `e2e/`.

Параметры URL для проверок:

- `?seed=42` — воспроизводимый бот (seeded RNG);
- `?botScript=grip,takedown,…` — сценарий бота (недоступные действия заменяются обычным выбором);
- `?gallery` — служебная галерея всех поз в обеих раскладках цветов (`?gallery=triangle&w=400`).

## Архитектура

| Слой | Файлы | Что делает |
| --- | --- | --- |
| Правила | `src/engine/catalog.ts`, `rules.ts`, `types.ts` | Чистый `resolveExchange(state, playerAction, botAction) → { nextState, events, report }`. Без DOM и таймеров. |
| Бот | `src/engine/bot.ts`, `rng.ts` | Взвешенный выбор из легальных действий; видит только открытое состояние. |
| Сессия | `src/session/session.ts` | Хранит правду схватки, заранее фиксирует выбор бота (1 раз на обмен/дуэль), блокирует ввод, проигрывает этапы, отменяет старые таймеры при реванше, ставит показ на паузу в фоне. |
| Кадры | `src/session/sequence.ts`, `timing.ts` | Из событий движка строит «попытка → ответ → итог», подписи и индикаторы. Длительности — в `timing.ts`. |
| Каталог визуализации | `src/visual/manifest.ts`, `poses.ts` | Явный манифест: позиция, контролирующий, приём, атакующий, фаза → поза. |
| Отрисовка | `src/visual/rig.ts`, `Fighter.tsx`, `Dojo.tsx`, `src/ui/*` | Векторный скелетный риг с IK, экран «Додзё». |

Фазы показа: `idle → playerAttempt → botResponse → result → idle`, перед попыткой и ответом —
короткая круговая анимация борьбы за захват. При `prefers-reduced-motion` последовательность та же,
без вращения и морфинга.

## Дизайн

Экран следует утверждённому макету «04 / Додзё» (`docs/reference-dojo.webp`): светлый голубой фон,
заголовок, плашка счёта «Вы 0 : 0 Бот», бойцы на круглом помосте, крупное название позиции,
метка «Ваш ход», кнопки и ссылка «История». Круглая кнопка паузы открывает меню (правила, карта позиций,
история, «Начать заново») и останавливает показ обмена.

Намеренные отличия от макета — по более поздним решениям задания:

- игрок в **чёрном** ги (на макете — синее);
- вместо одной крупной кнопки — **равнозначные разноцветные** кнопки, цвет = тип действия
  (вариант №1); недоступная по ресурсам техника — белая карточка, как вторичные кнопки макета;
- вместо таймера `04:32` — номер обмена: таймера, завершающего схватку, в правилах нет;
- добавлены ресурсы (захваты и дыхание) под счётом, подсказка и индикаторы у сцены.

## Визуализация

Бойцы нарисованы процедурно (SVG): объёмные сегменты с обводкой и бликом, ги с лацканом и поясом,
голова с причёской и лицом. Позы задаются ключевыми точками, локти и колени решает IK, поэтому
пропорции одинаковы во всех кадрах. Всего 46 поз:

- 6 базовых позиций; в партере роль «верхний/нижний» назначается чёрному или белому бойцу
  (игрок сверху ≠ отражение кадра, где бот сверху);
- 12 попыток переходов;
- 4 сабмишна × 7 фаз: попытка, зафиксирован, дожим, смена приёма, защита захвата, поворот, сдача (ТАП).

## Ограничения

- Бойцы на макете фотореалистичные; здесь — векторная стилизация. Фотореалистичных кадров для всех
  46 состояний нет, а подставлять фото только в стойку значит смешать два стиля.
- Утверждённые PNG-референсы (`Classic closed guard training.png`, `Low Half Guard Grappling Pose.png`,
  `Black gi full mount.png`, `Seated back control with double hooks.png`) в репозитории
  отсутствуют. Визуализация сделана по текстовому описанию и не воспроизводит их пиксель в пиксель.
- Это стилизованная 2D-графика в профиль: глубина (какая нога «ближе») передаётся слоями и оттенком,
  поэтому часть приёмов (боковой контроль, рычаг локтя) условна по сравнению с фотореференсами.
  Подставить утверждённые изображения можно, заменив отрисовку для записей манифеста.
- Шрифты системные (без сетевой загрузки).
